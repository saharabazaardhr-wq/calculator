# Sahara Bazaar: Control Center

- `index.html`: Sahara Bazaar calculator (GST / EMI)
- `control-center/`: **Control Center** app, Phase 0 + 1 (Team & Accountability)
- `CONTROL_CENTER_PLAN.md`: full phase-by-phase plan for all business areas

## Control Center: Phase 1 features
- Org chart, roles and KRAs for every role
- Tasks with one owner, a deadline, priority and photo/note proof
- Daily checklists (opening, temperature, F&V, shelf/expiry, cash closing, closing) with required photos
- Automatic escalation: L1 overdue → L2 manager (>2h) → L3 owner (>24h)
- WhatsApp reminders and morning huddle report
- Attendance with late marking
- 7-day accountability scorecard per person
- "Start blank" turns it into a template for any business

Open `control-center/index.html` in a browser (or via GitHub Pages at `/control-center/`).
Pilot mode stores data in the browser; the next step is a shared cloud database so every staff phone sees the same data.
